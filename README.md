# Quillframe - HTML Visual Editor

A single-file WYSIWYG HTML visual editor that runs entirely in the browser.

## Features

- Visual editing with click-to-select, drag-to-move, and resize handles
- Multi-select with Cmd/Ctrl-click and marquee box-select
- SVG element support (move and resize circles, rects, text, groups)
- Source code editor powered by CodeMirror 6
- AI annotation and adjustment via Qwen (DashScope) integration
- Responsive UI with scalable typography for large displays
- File open/save with native browser file picker
- Component palette with drag-and-drop insertion

## Usage

Open `index.html` directly in a modern browser (Chrome, Edge, Safari, Firefox).

### AI Features (Optional)

To use the AI annotation and adjustment feature, configure your DashScope API key in the settings panel. Note that due to CORS restrictions, the AI API may need a proxy when running from certain origins.
